# CI/CD Pipeline with GitHub Actions and Docker

## 1. Introduction
The objective of this project is to automate the testing and Docker image building process using GitHub Actions.

## 2. Abstract
A simple HTML website was created and packaged into a Docker image using NGINX. The source code was stored in GitHub, and GitHub Actions was configured to test the website content and build the Docker image automatically when code changes are pushed.

## 3. Tools Used
- Git
- GitHub
- GitHub Actions
- Docker Desktop
- HTML
- NGINX
- Windows PowerShell

## 4. Steps Involved
1. Created a simple HTML website.
2. Created a Dockerfile to package the website using NGINX.
3. Built and ran the Docker image locally.
4. Uploaded the project files to GitHub.
5. Created a GitHub Actions workflow.
6. Tested the website content and automatically built the Docker image.
7. Verified the workflow in the GitHub Actions tab.

## 5. Conclusion
This project helped me understand Git, GitHub, Docker, and CI/CD automation. It demonstrated how GitHub Actions can automatically test code and build a Docker image when changes are pushed to a repository.
